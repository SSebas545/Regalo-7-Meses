# Regalo 7 Meses

Aplicación web con HTML, CSS y JavaScript. El proyecto está en
`/home/sebas/GitHub/Regalo-7-Meses/`.

## Estructura

| archivo | qué es |
|---|---|
| `index.html` | la página |
| `styles.css` | los estilos |
| `script.js` | la lógica |

## Convenciones

- HTML, CSS y JavaScript planos. Sin framework ni build step: abrir
  `index.html` tiene que mostrar la aplicación funcionando.
- Los comentarios del código van en español.
